This is my example website's repository. The website is rendered from markdown (.md) files using [Quarto](quarto.org) and hosted online using [Github Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages). This setup predominately relies on plain language YAML (.yml) configuration files rather than web development knowledge.

Write markdown files in any plain text editor then render the whole website from the terminal with `quarto render`. I use and recommend [Obsidian](https://obsidian.md/), a robust and extensible plain text editor.

The website can be accessed [here](https://niboxr.github.io/Example-Quarto-Website/).
