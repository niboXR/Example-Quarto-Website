This is my example website's homepage. This website is rendered from markdown files using Quarto and hosted online using Github Pages. You and your team can write your markdown files in any plain text editor. I use and recommend Obsidian, a robust and extensible plain text editor. This setup predominately relies on plain language YAML configuration files (\_quarto.yml and \_brand.yml) rather than web development knowledge.

The Github repository can be accessed [here](https://github.com/niboXR/Example-Quarto-Website).
